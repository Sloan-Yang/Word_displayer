# 辞境 · LEXIS Word Atlas

把散落在 Markdown 里的单词、笔记和读过的书，变成一张可以漫游的地图。

一个用 Rust 写的桌面应用。它读取你的 Markdown 目录，把每条笔记之间的
`[[wikilink]]` 联系画成一张会呼吸的关系网；也能把读过的书按作家、按国度
点亮在一颗真三维地球上。为背单词、复习笔记、回顾阅读足迹而做，尽量好看。

> 起点是一个朴素的需求：我一次背一大团有联系的单词，想把它们画出来看。
> 后来长成了三个库共用一套引擎的「知识地图」。

## 三个库

应用左上角可以在三个库之间切换（也支持 `Ctrl+Shift+←/→`）：

- **单词** — 力导向的词网。每个单词**本身**就是节点（渐变胶囊），
  `[[链接]]` 就是连线，成团的近义/关联词自然聚在一起。默认只显示最近一周的
  所有单词，按 `Q`/`E` 一周一周地翻，天然适合按周复习。
- **笔记** — 同一套引擎，面向 Obsidian 式的笔记库。节点是圆点加标题，
  适合看笔记之间的引用结构。
- **阅读地图** — 一颗真正用 OpenGL 绘制、缓慢自转的三维地球。每位作家、
  每本书是漂在地球外的光点，尾巴连回作家所在的国度；地球用公有领域的
  Natural Earth 地形贴图，看得出大陆与海岸线。时间一长，你就知道自己
  读过哪个地区、哪个作家的什么书。

## 主要特性

- **力导向布局 + 气泡漂浮**：先退火铺开，收敛后转成带碰撞的缓慢漂浮，
  单词标签互相推开、永不重叠。
- **按时间筛选**：识别 `modified/YYYY-Www` 周标签，滑块选时间范围；
  越新的节点越实，越旧越淡。
- **标签筛选**：普通 / 只看 / 隐藏 三态循环，白名单加黑名单。
- **三维地球**：轨道相机（拖动或方向键环绕、滚轮/`+` `-` 缩放）、
  背面光点自动遮挡、经纬网、大气辉光；点光点看书、双击打开对应 md。
- **无边框圆角窗口**：自绘窗口外框，可拖动、可缩放，多屏之间一键归位。
- **常驻后台**：`Ctrl+9` 全局热键随时呼出 / 收起，隐藏时几乎不占 CPU。
- **明暗主题**、模糊搜索、贴合背景的界面底纹。

## 数据格式

每个库就是一个装着 `.md` 文件的目录。预置三个库的路径写在
`src/app.rs` 的 `preset_libraries()` 里，可自行修改，或在界面里临时加载别的目录。

**单词 / 笔记**（`D:\Code\Vocab`、`D:\Code\Lunarvim_Obsidian`）：

```markdown
---
tags:
  - modified/2026-W20    # 周标签，用于按时间筛选
  - academic             # 普通标签，用于标签筛选
---
# abalone
和 [[oyster]] 一样是贝类，参见 [[shellfish]]
```

正文里的 `[[目标]]` / `[[目标|别名]]` / `[[目标#小节]]` 会连成一条边。

**阅读地图**（`D:\Code\Reading`，每本书一个 md）：

```markdown
---
author: Albert Camus
country: France        # 中英文国家名都认；查不到就写 lat/lon 覆盖
region: Algiers        # 可选，地区标签
rating: 5              # 可选，1–5
date: 2026-W20         # 可选，复用周筛选
---
局外人的读后感……
```

## 构建与运行

需要 Rust 工具链（稳定版即可）。

```sh
cargo run --release                 # 打开默认库（单词）
cargo run --release -- "D:\Code\Reading"   # 指定目录 / 库启动
cargo run --release -- --stats      # 不开窗口，只打印解析统计
```

为 Windows 打造（无边框圆角窗口、全局热键、后台常驻都走 Win32），
但同样能在 Linux / macOS 上编译运行——那些平台特有的窗口特性会自动退化。

| 键 | 作用 |
| --- | --- |
| `Ctrl+9` | 呼出 / 收进后台 |

## 技术栈

Rust · [egui / eframe](https://github.com/emilk/egui) 0.31（glow / OpenGL 渲染）·
rayon（并行解析）· walkdir · image · windows-sys（Win32 窗口与热键）。

三维地球是在 egui 的 `PaintCallback` 里用原始 OpenGL 画的实心球（着色 +
陆海遮罩 + 地形贴图 + 程序化经纬网），漂浮的光点则用同一套视图矩阵投影成
2D 叠在上面，背面的点按相机射线自行遮挡。
